# CodeAlpha Image Gallery

This is a responsive image gallery project built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## Features

- Responsive image gallery layout
- Category filter buttons
- Lightbox image preview
- Next and previous image navigation
- Hover effects and smooth transitions
- Keyboard support for lightbox navigation

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open `index.html` in any web browser.

## Keyboard Controls

- Right Arrow: Next image
- Left Arrow: Previous image
- Escape: Close lightbox
